# Prima Materia listing kit: CurseForge

Files are in `branding/icon/` and `branding/banners/` (made with `scripts/make_branding.py`).

## Project fields

| Field | CurseForge |
|---|---|
| Project ID | not created yet (the Project Manager records it here and in `.github/scripts/publish_curseforge.py`) |
| Name | Prima Materia |
| Slug / URL | `prima-materia` (CurseForge fills this from the name) |
| Mod id | `primamateria` |
| Icon / logo | `icon/icon_512.png` (a 1024 px version is `icon/icon_1024.png`) |
| Class | Mods |
| Main category | Skyblock (or World Gen if Skyblock is not offered), plus Magic or Utility as a second category if wanted |
| Loaders | Forge and NeoForge |
| Game versions | Minecraft 26.2 and 26.3, one jar per Minecraft version |
| Environment | Client and Server |
| License | MIT |
| Source | https://github.com/ItMeCasey/PrimaMateria |
| Wiki | https://itmecasey.com/wiki/primamateria/ (not deployed yet) |
| Description | paste `curseforge/DESCRIPTION.md` (Markdown) |

### One-line summary (CurseForge summary field, 200 characters at most)

> Sieves, hammers, barrels and crucibles: build every resource from a void island, with an animated sieve, no screens and everything driven by datapacks.
